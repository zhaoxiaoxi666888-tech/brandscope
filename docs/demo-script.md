# BrandScope 90 秒演示录屏脚本

## 0–10 秒：产品定位

打开首页：“BrandScope 是面向品牌营销与 GTM 从业者的 AI 品牌研究工作台，它不是聊天机器人。”

## 10–25 秒：打开 Benchmark

点击“Apple 中国案例”，简短指出左侧固定工作流。

## 25–40 秒：Evidence

打开“资料证据”，展示来源等级、正文长度和引用次数：“模型读取的是清洗后正文，不是搜索摘要。”

## 40–55 秒：Research

切换两个研究模块，展示事实、AI 推断、营销意义和引用 Evidence。

## 55–70 秒：Insights

打开核心洞察：“AI 提供建议，用户负责修改和确认；只有已确认内容才会进入简报。”

## 70–85 秒：Brief

打开品牌营销简报，滚动展示九个章节和 Markdown 导出。

## 85–90 秒：结束

“BrandScope 的核心价值是把公开资料变成可追溯、可审阅、可继续修改的品牌工作成果。”
